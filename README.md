# Internship Tracker

This project is an Internship Tracker application developed to manage and track internship-related activities and tasks.

## Features
- Add and manage internship tasks
- Track project progress
- Store internship-related records
- Simple and user-friendly interface

## Technologies Used
- Python
- Flask
- React.js
- HTML
- CSS
- JavaScript

## Project Purpose
The purpose of this project is to simplify internship task management and progress tracking.
